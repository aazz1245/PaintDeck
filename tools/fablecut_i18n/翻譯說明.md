# 剪輯台（FableCut）介面翻譯說明

FableCut 是一套網頁影片剪輯器，原本只有英文介面。它嵌在「Anima 生圖站」的導演頁，叫「剪輯台」。
使用者是台灣人，大多不是工程師，用過剪映、威力導演、Premiere 中文版。請把介面翻成**繁體中文（台灣用語）**。

## 你拿到的檔案

`todo_NN.json` 是一個陣列，每一筆長這樣：

- `en`：要翻的英文原文。
- `ctx`：它出現在哪個檔案第幾行，後面接那一行程式碼的開頭。這是讓你判斷用途的，不用翻。

## 你要交的檔案

`done_NN.json`，編號跟 todo 一樣。內容是一個物件：`{"英文原文": "繁中譯文", …}`。

- **每一筆都要有**。鍵要跟 `en` 一字不差，連空白、標點、大小寫都一樣。
- 下面這些**不是介面文字**，值填 `null`：
  - 字型名稱（Arial、Segoe UI…）。
  - 程式內部用的鍵或路徑（例：`author:props.text`、`+faststart`）。
  - 編碼器、格式的專有名詞（`libx264`、`ProRes 422 HQ`、`H.264`、`AAC`）：如果整句只有專有名詞就填 null。有英文說明的要翻，例如「x265 (software)」→「x265（軟體編碼）」。
  - 單純的快捷鍵（`Shift+D`、`Ctrl+K`）。
  - 給 AI／API 看的開發者錯誤訊息：例如「must be an object like {shape:'ellipse', …}」「unknown parameter {0} (known: {1})」這種，裡面有程式碼範例或欄位名。不確定的時候就照翻，但程式碼、欄位名保留原文。
- 寫法：用 Write 工具寫成 UTF-8 的 JSON，寫完再用 Read 讀一次，確認是合法 JSON、筆數跟 todo 一樣。

## 規則

1. **{0}、{1}…是變數**，執行時會換成數字、檔名、時間，譯文裡要保留同樣的 `{0}`、`{1}`，可以調整順序。
   - 有些變數只是英文複數的 s 或 "is"/"are"，例如 `⚠ {0} file{1} offline`。這種譯文可以省略：`⚠ {0} 個檔案離線`。
   - 譯文**不能**出現原文沒有的 `{n}`。
2. **保留不翻**：
   - 快捷鍵寫法（Shift、Ctrl、Alt、⌘、←、→）。
   - 單位：px、fps、dB、LUFS、Hz、kHz、ms、%、×。
   - 檔案格式和技術縮寫：MP4、WebM、MOV、GIF、PNG、LUT、RGB、HDR、SDR、Rec.709、ffmpeg、HTTPS、URL、MCP、API、JSON。
   - 程式名：FableCut。
   - 開頭和結尾的符號照放，例如 `⬇ Export` →「⬇ 匯出」、`⚠ Offline:` →「⚠ 離線：」。
   - 結尾是 `…` 的照保留 `…`。
   - `IN` / `OUT` 單獨出現時（監看螢幕上的標示）照保留英文；出現在句子裡就翻成入點／出點。
3. **標點用全形**：，。：；？！（）「」。破折號 `—` 改寫成逗號或全形冒號。中文和英文、數字之間不加空白（`{0} fps`、`{0}%` 這種變數加單位的除外，照原文）。
4. **按鈕、標籤要短**：單字的按鈕盡量 2～4 個字（Export→匯出、Split→分割、Undo→復原）。說明句（title 提示）可以完整翻，口語、白話。
5. **用台灣用語**：影片、檔案、資料夾、預設、設定、視窗、滑鼠、按鍵、解析度、品質、支援、建立、刪除、復原、重做、載入、儲存、選取、拖曳、滑桿、核取方塊、下拉選單。不要用大陸用語：视频、文件（指 file 時）、默認、設置、鼠標、分辨率、質量、加載、保存。
6. **大小寫只是英文的寫法**，不用另外表現。
7. 不要加原文沒有的內容，也不要省略原文的意思。
